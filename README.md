# Java File Analyzer

## Project Overview

This project was developed as part of my Advanced Java Programming coursework at Madison College.

The Java File Analyzer is a program that reads text files, processes their contents, and generates information about the tokens found in those files.

## Features

- Reads and processes text files using Java.
- Counts the total number of tokens in a file.
- Identifies and counts distinct tokens.
- Generates output files containing analysis results.
- Uses multiple classes and interfaces to organize the program.
- Includes error handling for file processing.

## Technologies Used

- Java
- File I/O
- Object-Oriented Programming
- Java Collections
- Git and GitHub

## What I Learned

Working on this project helped me improve my understanding of Java programming, file handling, interfaces, and working with multiple classes.

I also gained experience troubleshooting errors, organizing code, and using GitHub to track changes throughout development.

## Project Purpose

The purpose of this project was to practice Java programming concepts and develop a working application that analyzes text files.
